# SdfFontFix: vanilla dependencies (format: _guide/README.md "바닐라 의존 목록")
# checked: 42.21.0
#
# kind	target	note

data	media/fonts/{KO,JP,CH,CN,TH}/fonts.txt	ours replace the vanilla ones: tools/make_fonts_txt.sh copies each and appends the Sdf* fonts. Rerun after a game update that changes one
data	media/fonts/<LANG>/4x/<Large font>	the font every Sdf* name maps to, taken from the "Large" entry of each vanilla fonts.txt: zomboidLargeKorean (lineHeight 45, same as SDF), zomboidLargeJapanese / zomboidLargeChinese / zomboidLargeThai (lineHeight 50)
assume	SDF fonts lack only KO JP CH CN TH	media/fonts/sdfRegular.fnt has 873 glyphs (Latin 335, Cyrillic 275, Greek 75); checked against every vanilla translation 2026-10-30, other languages miss only emoji/dash marks. A new language with its own script needs its own fonts.txt
data	UIFont Sdf* names	SdfRegular SdfItalic SdfBold SdfBoldItalic SdfOldRegular SdfOldBold SdfOldItalic SdfOldBoldItalic SdfRobertoSans SdfCaveat (media/fonts/EN/fonts.txt). A new Sdf* font would still show '?'
assume	TextManager.Init reads EN then <lang> fonts.txt	zombie.ui.TextManager.Init: entries of <lang>/fonts.txt override EN ones by name. If <lang> stops being read after EN, the mod does nothing
assume	TextManager.getFontFilePath	tries media/fonts/<lang>/<sizeDir>/<fnt>, then media/fonts/<lang>/<fnt>: "4x/<font>" lands on <lang>/4x/ for every font size option. If the lookup changes, the font may not be found (text vanishes or falls back)
assume	TextManager.Init after loadMods	zombie.GameWindow.init: initFonts() runs again after loadMods("default"). Fonts come only from mods enabled in the main-menu mod list, and only after a game restart
assume	AngelCodeFont page path	pages resolve next to the .fnt, so the vanilla 4x pages load from the game folder
data	Tooltip_FishingTip (JP)	Translate/JP/Tooltip.json overrides it (Translator.tryFillMapFromMods merges mod keys over vanilla). Line count matches EN (12 <br> parts, the tension gauge sits in the blank lines); recheck if EN changes or JP gets translated
assume	CN uses CH glyph set	CN/*/zomboidLargeChinese.fnt has 15862 glyphs and lacks 874 simplified characters the CN translation uses; we inherit those blanks
