title=Korean SDF Font Fix
description=[h1]Korean SDF Font Fix[/h1]
description=In Build 42 the new windows (the fishing panel, the build menu, newspapers and flyers) use new SDF fonts that have no Hangul, so Korean text there shows as question marks. This mod maps those fonts to the game's own Korean font, so the text is readable.
description=
description=[h2]Notes[/h2]
description=[list]
description=[*]Only active when the game language is Korean. Other languages are unchanged.
description=[*]Fonts load at startup: enable the mod in the main menu mod list, then restart the game.
description=[*]Uses the game's own large Korean bitmap font, the same at every font size setting. In those windows English text also uses it, and bold, italic and serif styles look the same.
description=[*]Fonts only: no Lua, no gameplay change, safe to add to or remove from an existing save.
description=[/list]
description=
description=[h2]한국어[/h2]
description=B42의 새 창(낚시 창, 건설 메뉴, 신문·전단)은 한글이 없는 새 SDF 폰트를 써서 한국어가 [b]???[/b]로 나와요. 이 모드는 그 폰트들을 게임에 들어 있는 한국어 폰트로 바꿔 한글이 제대로 보이게 해요. 게임 언어가 한국어일 때만 동작해요. 폰트는 게임을 켤 때 읽으니, 메인 메뉴 모드 목록에서 켠 뒤 [b]게임을 다시 시작[/b]해 주세요. 폰트만 바꾸므로 기존 세이브에 넣고 빼도 돼요. 그 창들에서는 영문도 한국어 폰트로 나오고, 굵게·기울임 구분이 없어져요.
